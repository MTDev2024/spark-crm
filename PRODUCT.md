# Produit

Copilote IA de prospection commerciale. Ce n'est ni un simple CRM, ni un chatbot, ni un générateur de messages génériques.

Cycle : prospect → contexte → qualification → méthode → action → résultat → débrief → prochaine action.

## Principes

- **Ne pas inventer.** Une information inconnue reste inconnue ; l'IA ne comble jamais un champ.
- **Complétude ≠ exploitabilité.** Une fiche incomplète peut être qualifiée ; chaque action n'exige que ses propres informations.
- **Pas de besoin fabriqué.** « Aucune opportunité suffisamment établie pour le moment » est une conclusion valide.
- **L'IA propose, l'utilisateur décide** : accepter, modifier, rejeter, régénérer.
- **Chaque interaction** débouche sur une prochaine action avec échéance, ou explicitement sur aucune.
- **Débrief plutôt qu'enregistrement** : l'enregistrement d'appels n'est pas requis.
